## GranaFlow 

O GranaFlow permite registrar e acompanhar despesas do dia a dia de forma simples e organizada.

## Funcionalidades

- Cadastro de gastos com descrição, valor e categoria.
- Exibição da lista de gastos cadastrados.
- Cálculo automático do total acumulado.
- Exclusão individual de gastos.
- Opção para limpar todos os gastos, com confirmação.
- Destaque visual para gastos acima de R$ 100,00.
- Validação dos campos antes de salvar.
- Armazenamento dos dados com AsyncStorage.
